# PINTU Karir — working notes

Career and income platform for Indonesian students at NTU Singapore.
Three surfaces over one graph of people: **gigs**, **mentorship**, **referrals**.

**Read `docs/BRIEF.md` end to end before each phase.** It is the spec, and every
requirement in it traces back to a judging-rubric row. Follow `docs/DECISIONS.md`
exactly; to deviate, say so and wait.

## Architecture

```
src/app/          Routes (App Router). 16 routes — see DECISIONS.md §3.
src/components/
  ui/             Primitives. Restyled Radix; default shadcn is a visual tell.
  layout/         AppShell, SideRail, TopBar, BottomTabs
  domain/         GigCard, MentorCard, ReferralCard, FeedCard, trust components
  signature/      ThresholdRail, GapuraReveal, PathwayMap  <- the product's argument
  demo/           DemoControls, JudgeTour
src/lib/
  types.ts        Domain contract
  repo/           Repo interface + mock.repo (seeded) + supabase.repo (stub)
  ranking/        rankByHorizon()   TODO(logic)
  matching/       scoreMatch()      TODO(logic)
  verification/   tierFor()         TODO(logic)
src/mock/         seed.ts, generators.ts, scenarios.ts
src/content/      copy.ts — every user-facing string
src/stores/       zustand: threshold value, persona, demo state, filters
docs/reference/   v0 prototype (reference only) + contrast checker
```

**The rule: components never know where data comes from.** They call the repo
interface through React Query. Swapping the mock for a real backend must not
touch a single component.

## Conventions

- **TypeScript strict.** No `any`, no `@ts-ignore` — both are ESLint *errors*, so
  they fail the build. Use `@ts-expect-error` with a description if truly needed.
- **No hardcoded user-facing strings.** Everything comes from `src/content/copy.ts`,
  via `useCopy()`. A hardcoded sentence in a component is a bug. Indonesian is the
  default locale; English toggles in settings.
- **No arbitrary values in components.** Every colour, size, space and radius traces
  to a token. No raw `font-size`, no magic pixels.
- **Tailwind is v4** — CSS-first. Tokens live in `globals.css` under `@theme`.
  There is no `tailwind.config.ts` and adding one is the wrong move.
- **Next is 16.x** and its APIs differ from model training data. Read
  `node_modules/next/dist/docs/` before using an App Router API you are unsure of.
  `AGENTS.md` (imported above) is regenerated by `next dev` — commit it, don't fight it.
- **Zero outbound network at runtime.** Fonts self-hosted via `next/font`, images
  local, all data local. Venue wifi must be irrelevant to the demo. This single
  constraint protects 30% of the score.
- **`'use client'` at the leaves.** Keep it off layouts and pages where possible.
- **Every async surface implements five states**: loading (skeleton matching final
  dimensions, never a spinner on a list), empty, filtered-empty, error, success.
- **Accents are fills first, text second.** See DECISIONS.md §2.5 — several
  accent-as-text pairings fail AA. Gold is never text on a light surface.
- **No real names, companies, or photographs.** Mock data is generated
  deterministically from one seed. A specific fact (a company, a rate, a policy) is a
  `TODO(content)` and belongs in `docs/HANDOFF.md`.
- **Small commits**, conventional messages, one concern each. Every commit builds.

## Motion

One orchestrated moment — the gapura reveal, once per session, skippable, replaced
by a fade under `prefers-reduced-motion`. Everywhere else: 120–180ms feedback and
layout-animated reordering. Nothing loops, floats, or parallaxes. Scattered animation
is the strongest tell that a UI was generated rather than designed.
